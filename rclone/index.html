ProjectOne

ProjectOne is a private, single-user OAuth client used by the owner of this site with rclone, an open-source command-line tool for cloud storage.

What it does

The application lets rclone access the owner's own Google Drive in order to mount it as a local folder and keep personal files (such as an encrypted password database) synchronised between the owner's computers and phone.

  • It is used only by the site owner and is not offered to the public.
  • It reads and writes files only in the owner's own Google Drive.
  • It has no server component; all processing happens on the owner's devices.

See the Privacy Policy.
