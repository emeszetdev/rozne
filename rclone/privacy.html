Privacy Policy

Last updated: 25 November 2026

This policy describes how ProjectOne, a private OAuth client used with rclone, handles Google user data.

Who uses the application

The application is used solely by its owner to access the owner's own Google account. It is not distributed to or used by anyone else.

Data accessed

With the owner's consent, the application accesses files in the owner's Google Drive (scope https://www.googleapis.com/auth/drive) in order to list, read, write and synchronise those files.

How data is used and stored

  • Files are transferred only between Google Drive and the owner's own devices.
  • OAuth tokens and cached file copies are stored only locally on the owner's devices.
  • No data is sent to any server operated by the developer or to any third party.
  • No data is sold, shared, used for advertising, or used to train AI/ML models.

Compliance

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens can be deleted by removing the rclone configuration.

Contact

Questions about this policy can be raised via GitHub Issues.
